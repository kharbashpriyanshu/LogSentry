# Contributing to LogSentry

We welcome contributions! LogSentry is designed to be an extensible SIEM platform.

## How to Contribute
1. Fork the repository.
2. Create a new branch for your feature or bug fix.
3. Make your changes, ensuring you follow the existing Clean Architecture principles.
4. Write tests for any new functionality (minimum 65% coverage required).
5. Submit a Pull Request.

## Development Setup
Please refer to the Local Development section in `README.md` to set up your environment.

## Code Style
- We use Python 3.11+.
- Code should be strictly typed (`mypy`).
- Please follow standard `PEP 8` formatting.
