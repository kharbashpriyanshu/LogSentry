# Security Policy

## Supported Versions
Currently, only the `main` branch (v1.0.0-rc) is actively supported for security updates.

## Reporting a Vulnerability
We take the security of LogSentry seriously. If you discover a security vulnerability, please do NOT open a public issue. 

Instead, please send a direct message or email to the repository owner with details of the vulnerability, steps to reproduce, and potential impact. We will review the report and work on a patch as quickly as possible.
